# Chronic Chain

A Cosmos SDK blockchain for the Chronic Token (CHT) with CosmWasm smart contracts built in, plus a Vue web app and a Flutter mobile wallet.

The chain was scaffolded with Starport and runs on Cosmos SDK 0.44 with IBC. Its custom `cht` module is the CosmWasm `wasm` module under a new name, so you can upload, instantiate, execute and migrate Rust smart contracts on it, and governance can store or pin code through proposals.

## Tokens and network

- `cht`: the Chronic token
- `cgas`: used for staking, minting, governance deposits and fees
- Addresses start with `chronic`
- The local dev chain ID is `chronic-grapes`

## Running the chain locally

You'll need Go 1.17 and [Starport](https://docs.starport.com) (now Ignite CLI).

```bash
git clone https://github.com/AI-pro017/chronic-chain.git
cd chronic-chain
starport chain serve
```

This builds the `chtd` binary, creates a local chain from `config.yml` and starts it. The accounts `alice`, `austin` and `carlos` are funded at genesis, `alice` is the validator and `austin` runs the faucet.

Uploading and running a contract looks like this:

```bash
chtd tx cht store contract.wasm --from alice --gas auto
chtd tx cht instantiate 1 '{}' --label "my contract" --from alice
chtd query cht list-contract-by-code 1
```

## Web app

```bash
cd vue
npm install
npm run serve
```

The Vue app was generated by Starport and talks to the local chain for balances, transfers and module queries.

## Mobile wallet

The `flutter/` folder holds a Flutter wallet for Android and iOS. It can:

- create a new wallet or import one from a mnemonic, with a backup and confirm step
- lock the wallet behind a passcode
- show balances for every token on the chain
- send tokens with a default or custom fee
- show transaction history

To run it, install Flutter and run `flutter run` inside the `flutter` folder. To point it at a chain other than localhost, pass the API address:

```bash
flutter run --dart-define=BASE_LCD_URL=your-node-address --dart-define=PORT=1317
```

## Project structure

```text
app/        Chain setup, including the wasm keeper and ante handler
cmd/chtd/   The node binary
x/cht/      Smart contract module (CosmWasm)
proto/cht/  Protobuf definitions for the module
docs/       OpenAPI spec and Swagger UI
vue/        Web app
flutter/    Mobile wallet
```
